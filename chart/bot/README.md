# 텔레그램 자동화 봇

GitHub Actions 위에서 **실시간**으로 돌아갑니다 (`.github/workflows/chart-alert.yml` → `daemon.js`). 서버가 필요 없습니다.
필요한 시크릿은 `TELEGRAM_BOT_TOKEN` 하나이고, 봇에게 처음 메시지를 보낸 사람이 주인으로 등록됩니다.

- 한 번 실행되면 약 5시간 40분 동안 상주하면서 텔레그램 메시지에 **몇 초 안에** 답합니다.
- 끝날 때 다음 실행을 스스로 예약해서 24시간 이어지고, 3시간마다 도는 예약 실행이 끊김을 대비합니다.
- 공개 저장소라 Actions 사용 시간은 무료입니다.
- 멈추려면 Actions 탭 → **차트 알림 봇** → `···` → **Disable workflow**.
- 상태(`state.json`)는 바뀌었을 때 최대 10분마다 커밋됩니다. 공개 저장소이므로 알림 메모나 감시 URL에 개인정보를 넣지 마세요.

## ✈️ 여행 비서 (`trip.json`, `trip.js`)

일정은 `trip.json`에 있습니다 (11/17 포르투 → 12/6 인터라켄, 여행 플래너 `index.html`과 같은 일정). 바꾸려면 이 파일을 고치면 됩니다.

**지출 기록: 슬래시 없이 그냥 보내기**
- `점심 18유로`, `택시 12.5chf`, `€4.5 젤라또`, `숙소 도시세 8유로 현금`
- 여행 중에는 단위 없이도 됩니다: `커피 3.2` → 그날 도시의 통화(EUR/CHF)로 기록
- `항공권 1,250,000원`처럼 출발 전 지출은 "출발 전"으로 따로 집계
- 기록 시점의 실시간 환율로 원화 환산, 식사·커피·교통·쇼핑·입장·숙소·기타 자동 분류
- 잘못 적었으면 `/undo`

**환산**: `50유로 얼마`, `30chf?`, `10만원`, `/won 50유로`

**명령**
- `/trip` 전체 일정과 D-day · `/today` 오늘 도시, 날씨, 이동, 안전 팁, 오늘 지출
- `/spent` 오늘 · `/spent 어제` · `/spent 전체` · `/spent 바르셀로나`
- `/budget 300만원` 예산 설정 → 남은 돈과 남은 날 기준 하루 예산 표시
- `/check` 출발 전 체크리스트 (D-35 알람브라 예약 … D-1 온라인 체크인) · `/done 번호`
- `/export` 지출 내역 CSV 파일 (엑셀/구글시트)

**자동으로 오는 메시지**
- 출발 전: 매일 아침 브리핑에 D-day와 지금 해야 할 체크리스트
- 여행 중: **현지 시간 오전 8시** 아침 브리핑 (Day N, 도시 날씨, 이동 예고, 안전 팁, 환율, 어제 지출, 예산) — 한국 9시 브리핑과 관심종목 요약도 현지 아침으로 옮겨짐
- 여행 중: **현지 시간 21시** 오늘 지출 정리, 다음 날 이동 알림
- 귀국 다음 날: 여행 전체 지출 정리

**개인정보**: 지출 내역은 `trip-data.enc`에 봇 토큰으로 만든 키로 **암호화**해서 저장합니다(AES-256-GCM). 공개 저장소에도 내용은 보이지 않습니다. 봇 토큰을 바꾸면 이전 기록은 읽을 수 없게 됩니다(`.bak`으로 보관).

## 명령어 (텔레그램 입력창에서 `/`를 누르면 메뉴로 나옵니다)

**가격 알림**
- `/alert BTCUSDT 90000` — 현재가보다 높으면 돌파, 낮으면 하회 알림 (자동 판단)
- `/alert USDKRW <1350 환전` — 방향 지정 + 메모
- `/alert NVDA -5%` — 지금 가격 기준 퍼센트
- `/alerts`, `/unalert 번호`, `/unalert all`

**아침 브리핑과 날씨**
- `/brief` — 지금 브리핑 받기
- `/weather [도시]` — 날씨 (예: `/weather 파리`, `/weather Interlaken`)
- `/city 도시` — 브리핑 도시 변경 (여행 중이면 현지 도시로)

**웹페이지 감시**
- `/watch https://... 품절` — "품절"이라는 글자가 사라지면(재입고) 알림
- `/watch https://...` — 페이지 글자가 바뀌면 추가/삭제된 줄을 알림
- `/watches`, `/unwatch 번호`
- 자바스크립트로만 그려지는 페이지와 로그인이 필요한 페이지는 감시가 안 됩니다. 시간처럼 계속 바뀌는 글자가 있는 페이지는 키워드 방식을 쓰세요.

**차트 분석**
- `/now 종목`, `/summary`, `/list`, `/add 종목 [이름]`, `/remove 종목`, `/tf 1h|4h|1d|1w`, `/paper`
- `/status` — 실시간 모드 여부, 마지막 분석 시각, 알림/감시 개수

**한글 이름**: 비트코인, 이더리움, 리플, 솔라나, 도지, 달러, 유로, 엔화, 위안, 파운드, 프랑, 코스피, 코스닥, 삼성전자, 하이닉스, 네이버, 카카오, 현대차, 셀트리온, 엔비디아, 테슬라, 애플, 마이크로소프트, 구글, 아마존, 메타 — 모든 명령에서 사용 가능 (`/alert 비트코인 -5%`)

종목 표기: 미국 `NVDA` · 한국 `005930` · 바이낸스 `BTCUSDT` · 업비트 `KRW-XRP` · 환율 `USDKRW`, `EURKRW`, `JPYKRW`
